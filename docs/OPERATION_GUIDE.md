# CS2 HVH 黑信榜 - 系统操作指南

## 1. 系统概览
本系统旨在维护 CS2 HVH 社区环境，提供曝光、审核、投诉处理及系统管理功能。

## 2. 后台管理登录
*   **访问地址**: `/admin` (例如: `http://localhost:5173/admin`)
*   **初始化**: 首次访问如果未检测到管理员，会提示进行初始化设置，需输入 `ADMIN_KEY` (后端环境变量配置) 来创建第一个管理员账号。
*   **登录**: 使用管理员账号密码登录。

## 3. 曝光审核管理
管理员可对用户提交的曝光信息进行审核与管理。
*   **列表视图**: 支持网格和列表两种视图切换。
*   **搜索与筛选**:
    *   支持按标题/被曝光人搜索。
    *   支持按发布者 IP 搜索。
    *   支持按状态（审核中、已通过、已拒绝）筛选。
*   **审核操作**:
    *   **通过**: 点击“通过”按钮，曝光将正式发布并在首页可见。
    *   **拒绝**: 点击“拒绝”按钮，曝光将被标记为拒绝。
    *   **隐藏/显示**:
        *   点击“隐藏”按钮（红色/橙色），该条目将在前端不可见。
        *   点击“显示”按钮，恢复可见。
    *   **排序**: 可在列表视图中修改排序权重（数字越大越靠前）。
    *   **详情**: 点击“查看”可预览完整内容及证据图片。

## 4. 投诉管理
处理用户针对曝光内容的投诉。
*   **查询**: 支持按状态（待处理、处理中、已解决）和关键词搜索。
*   **处理流程**:
    1.  点击“查看/处理”。
    2.  查看投诉详情及证据截图。
    3.  在下方表单中选择新状态（如“已解决”）。
    4.  填写“处理备注/结果”（必填），向用户反馈处理情况。
    5.  点击“保存处理”。
*   **记录**: 系统会自动记录处理人及处理时间。

## 5. 系统设置
### 5.1 公告管理
*   **发布**: 填写标题、内容（支持富文本），选择状态（显示/隐藏）。
*   **显示规则**: 公告发布后，用户访问首页时会弹出提示。用户可选择“今日不再提示”。若发布新版本公告，所有用户将再次看到弹窗。

### 5.2 广告管理
*   管理首页侧边栏广告。
*   **字段**: 标题、图片URL、跳转链接、投放时间、状态。

### 5.3 音乐设置
*   管理首页背景音乐。
*   **支持格式**:
    *   MP3 直链。
    *   网易云音乐等平台的 iframe 外链代码。
*   **自动播放**: 系统尝试自动播放，若浏览器拦截，用户需手动点击播放。

## 6. 日志审计
### 6.1 操作日志
*   记录管理员的所有敏感操作（如删除、审核、配置修改）。
*   支持按操作人、动作类型、时间范围筛选。
*   点击“详情”可查看具体修改的数据内容。

### 6.2 访问日志
*   记录曝光页面的访问情况。
*   支持导出 CSV 文件。

### 6.3 用户行为日志
*   记录普通用户的关键操作。

## 7. 内容与用户管理
*   **内容管理**: 修改网站标语、隐私协议、服务条款等静态内容。
*   **用户管理**: 创建/编辑管理员或普通用户，禁用/启用违规账号。
